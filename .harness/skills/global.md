# Global Skills & Protocols

### 🌐 Language Policy
- **Primary Language**: Always communicate with the user and other agents in **Korean (한국어)**.
- **Tone**: Maintain a professional, collaborative, and clear tone. Use polite language (존댓말).
- **Code & Tech Terms**: Keep technical terms (e.g., API, Refactoring, Thread) in English where appropriate for clarity, but the surrounding explanation must be in Korean.

### 🤝 Collaborative Protocol
- Be concise but thorough.
- If an action might be destructive, explicitly ask for human approval.
- When handing off to another agent, summarize what you've done in Korean.
