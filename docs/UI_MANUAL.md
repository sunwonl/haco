# 🖥️ HarnessCore Web UI 상세 매뉴얼

HarnessCore의 웹 인터페이스는 에이전트들의 활동을 시각화하고, 시스템을 제어하며, 결과물을 확인하는 통합 관제소입니다.

---

## 1. 메인 대시보드 (Main Dashboard)

### Workspace (작업 공간)
- **에이전트 타임라인**: 좌측 영역에는 에이전트들이 주고받는 메시지, 사고 과정(Thought), 도구 실행 결과(Action/Result)가 타임라인 순으로 표시됩니다.
- **실시간 업데이트**: 백엔드에서 에이전트가 동작할 때마다 화면이 자동으로 스크롤되며 최신 상태를 유지합니다.

### Memory (기억 저장소)
- 사이드바의 **Memory** 탭을 클릭하여 현재 프로젝트의 지식 베이스를 확인합니다.
- **지식 타임라인**: 세션별로 어떤 중요한 지식이 저장되었는지 타임라인 형식으로 조회할 수 있습니다.

---

## 2. 상단 제어바 (Top Bar)

### ⚙️ 설정 (Settings)
시스템의 핵심 설정을 변경하는 모달 창입니다.
- **General**: 사용할 LLM 모델(Gemini 1.5 Pro/Flash 등)과 GCP 위치 정보를 설정합니다.
- **MCP Servers**: 에이전트에게 새로운 '능력'을 부여합니다. 외부 MCP 서버 실행 명령을 등록하여 에이전트가 GitHub 연동이나 메모리 서버를 사용하게 할 수 있습니다.
- **Skills**: 에이전트의 '성격'과 '지식'을 튜닝합니다. 마크다운 형식으로 작성된 지침(System Instructions)을 에이전트별로 편집할 수 있습니다.

### 📟 콘솔 (Console)
시스템의 '블랙박스' 역할을 합니다.
- **전체 로그**: API 요청, 에이전트 내부 통신 등 모든 시스템 로그를 확인합니다.
- **필터링**: 특정 에이전트의 로그만 골라 보거나, 에러 로그만 필터링하여 디버깅에 활용할 수 있습니다.

---

## 3. 사이드바 (Sidebar)

### 📂 탐색기 (Explorer)
- 현재 작업 중인 프로젝트의 파일 구조를 보여줍니다.
- **파일 미리보기**: 파일을 클릭하면 중앙 모달로 코드 내용을 즉시 확인할 수 있습니다.

### 🧠 메모리 (Memory)
- 에이전트가 `add_memory` 도구로 저장한 중요한 사실들을 보여줍니다. (예: "사용자는 항상 React 18 사용을 선호함")

---

## 4. 고급 조작법 (Tips)

### 에이전트 개입하기
에이전트가 루프에 빠지거나 잘못된 방향으로 가고 있을 때, **콘솔**을 통해 현재 진행 상황을 파악하고 필요시 설정을 변경하여 에이전트의 행동을 교정할 수 있습니다.

### UI 커스터마이징
HarnessCore UI는 모던한 글래스모피즘(Glassmorphism)과 다크 모드가 적용되어 있습니다. 모든 컴포넌트는 반응형으로 설계되어 있어 다양한 화면 크기에서 최적화된 뷰를 제공합니다.

---

> [!IMPORTANT]
> 설정 변경 후에는 **[Save & Reload]** 버튼을 눌러야 에이전트의 다음 실행부터 반영됩니다.
