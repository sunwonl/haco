# [IR-020] 저널 기록 다국어화 (Journal Language Localization) 구현

**날짜**: 2026-04-13  
**단계**: Phase 5.7 — 사용자 경험 (UX) 고도화

---

## 구현 배경

기존 `journals.md` 기록은 영문으로 고정되어 있어, 한국어 환경에서 작업하는 사용자가 활동 내역을 한눈에 파악하기 다소 불편한 점이 있었습니다. 이를 해결하기 위해 `settings.json` 설정을 통해 기록 언어를 변경할 수 있는 기능을 추가했습니다.

---

## 주요 구현 내용

### 1. 설정 항목 추가 (`loader.py`)
`HarnessConfig` 모델에 `language` 필드를 추가했습니다.
*   **기본값**: `"en"`
*   **지원 예정 언어**: `"en"`, `"ko"` (현재 두 언어에 대한 변환 맵 구현 완료)

### 2. `Journaler` 유틸리티 고도화 (`journaler.py`)
*   **I18n 맵 도입**: `Status`, `Summary`, `Reasoning`, `Affected Files` 등의 마크다운 헤더를 언어별로 매핑했습니다.
*   **동적 헤더 생성**: `log_activity` 호출 시 전달받은 `language` 서버 세팅에 따라 맞춤형 헤더를 사용하여 기록을 남깁니다.
*   **초기 타이틀 로컬라이징**: 파일이 없을 때 생성되는 저널의 제목(`# HarnessCore Activity Journal` 등)도 언어 설정을 따릅니다.

### 3. 전체 에이전트 노드 연동
*   **PO 노드 포함**: 모든 전문 에이전트(`SA`, `CD`, `UI`, `QA`, `DR`)는 물론, 오케스트레이션을 담당하는 `PO` 노드에서도 저널을 기록하도록 구성했습니다.
*   **설정 전파**: 각 에이전트는 `config.language` 값을 `Journaler.log_activity`에 전달하여 일관된 언어로 기록을 유지합니다.

---

## 실행 및 설정 방법

`.harness/settings.json` 파일에서 다음과 같이 언어를 설정할 수 있습니다:

```json
{
  "language": "ko",
  "llm": { ... }
}
```

한국어(`ko`)로 설정 시 `journals.md`에 다음과 같이 기록됩니다:

*   **상태**: ✅ `SUCCESS`
*   **요약**: 사용자 요구사항 분석 및 아키텍처 설계 완료
*   **추론**: 모듈화된 설계를 위해 ...
*   **토큰 사용량**: 🪙 `in: 500` | `out: 200` | `think: 0`
