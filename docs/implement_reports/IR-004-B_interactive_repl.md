# [IR-004-B] 대화형 인터페이스 (Interactive REPL) 및 .env 지원

**날짜**: 2026-04-12  
**단계**: Phase 1 보완 — 사용자 인터페이스 확장

---

## 구현 배경

기존 `harness cli "프롬프트"` 방식은 일회성 명령 실행에는 적합하지만, 에이전트와 지속적으로 소통하거나 추가 지시를 내리기에는 불편함이 있었습니다. 또한, 매번 환경변수를 터미널에 export해야 하는 번거로움을 해결하기 위해 `.env` 파일 지원을 추가했습니다.

---

## 구현 내용

### 1. `.env` 파일 자동 로드
- `python-dotenv` 패키지를 프로젝트 의존성에 추가 (`uv add python-dotenv`)
- `src/harnesscore/cli.py` 상단에서 `load_dotenv()`를 호출하여 실행 시 현재 디렉토리의 `.env` 파일을 자동으로 환경변수로 로드하도록 수정

### 2. 대화형 인터페이스 (`harness chat`) 구현
새로운 서브커맨드 `harness chat`을 추가했습니다.

- **연속성 유지**: LangGraph의 `thread_id`와 `FileCheckpointer`를 활용하여 세션 내 상태가 유지됩니다.
- **실시간 스트리밍**: 각 에이전트 노드가 종료될 때마다 행동 요약(`details`)과 다음 라우팅 정보를 실시간으로 출력합니다.
- **세션 제어 명령어**:
  - `exit`, `quit`: 세션 종료
  - `/reset`: 새로운 `thread_id`를 생성하여 상태 초기화
- **유연한 입력**: 매 turn마다 사용자의 새로운 요청을 받아 에이전트 루프를 재개합니다.

### 3. CLI 구동 방식 개선
- `cli` 커맨드 (`harness cli "..."`): 기존의 일회성 실행 방식 유지
- `chat` 커맨드 (`harness chat`): 대화형 REPL 방식 제공

## 검증 결과

1. **`.env` 로드 테스트**: `GEMINI_API_KEY`가 `.env` 파일로부터 정상적으로 읽히는 것을 확인 (`uv run python` 스크립트 검증 완료)
2. **REPL 루프 테스트**: `harness chat` 실행 시 사용자 입력을 기다리고, 입력 후 PO 노드가 동작하여 라우팅 결과를 출력하는 흐름 확인
