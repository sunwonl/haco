# [IR-004-C] REPL 고도화 및 에이전트 대화 능력 강화

**날짜**: 2026-04-12  
**단계**: Phase 5 보완 — 사용자 경험(UX) 및 상호작용성 개선

---

## 구현 배경

1. **REPL 입력 개선**: 기존 `input()` 방식은 한글 입력(IME) 시 글자 꼬임 현상이 발생하거나, 명령어 히스토리 기능이 없어 대화형 인터페이스로서 한계가 있었습니다.
2. **에이전트 인격화**: 에이전트가 단순히 코드를 짜는 기계 역할이 아니라, 사용자의 질문에 답하고 현재 상황을 말로 풀어서 설명할 수 있는 '대화 상대'로서의 능력이 요구되었습니다.

---

## 구현 내용

### 1. `prompt_toolkit` 도입 및 REPL 강화
- **라이브러리 교체**: `typer.prompt`를 `prompt_toolkit`의 `PromptSession`으로 교체.
- **한글 지원**: 다중 바이트 문자 및 IME 입력을 완벽하게 지원하여 한글 타이핑 시의 불편함 해소.
- **히스토리 기능**: 세션 내에서 위아래 방향키를 이용해 이전에 입력한 명령어를 다시 불러올 수 있는 `InMemoryHistory` 적용.

### 2. PO 에이전트의 대화형 로직 개선 (`po.py`)
- **스키마 확장**: `PORoutingDecision`에 `response_to_user` 필드 추가.
- **프롬프트 고도화**: PO가 에이전트들의 관리자일 뿐만 아니라 사용자의 비서로서 동작하도록 지시.
  - 사용자의 단순 질의(질문, 인사 등)에 친절하게 답변 가능.
  - 코드 작업이 필요 없는 경우 `FINISH`로 라우팅하며 답변만 제공.
  - 진행 상황을 '내부 reasoning'이 아닌 '사용자용 메시지'로 풀어서 전달.

### 3. CLI 출력 정렬 (`cli.py`)
- PO 에이전트가 생성한 `response_to_user` 메시지를 CLI 화면 전면에 노출하여 사용자와 에이전트 간의 연결감 강화.

---

## 검증 결과

- **한글 테스트**: `harness chat` 모드에서 한글 문장이 꼬임 없이 정상 입력됨을 확인.
- **대화 테스트**: "안녕? 너는 누구니?" 같은 질문에 PO 에이전트가 본인의 역할을 설명하며 대화를 이어가는 것을 확인.
