# [IR-012] HITL (Human-In-The-Loop) 및 워크플로우 승인 프로세스 도입

**날짜**: 2026-04-12  
**단계**: Phase 5 — 대화형 협업 고도화

---

## 구현 배경

자율 에이전트가 예기치 않은 방향으로 작업을 진행하거나, 불확실한 상황에서 추측만으로 코드를 수정하는 것을 방지하기 위해 사용자의 개입(Human-In-The-Loop)이 필수적이었습니다. 특히 복잡한 작업 시작 전 PO의 계획을 사용자가 검토하고 승인하는 절차가 필요했습니다.

---

## 구현 내용

### 1. PO 에이전트의 명시적 도움 요청 (`po.py`)
- **`HUMAN` 라우팅 추가**: PO가 판단하기에 정보가 부족하거나 사용자의 결정이 필요한 경우 `next_agent`를 `HUMAN`으로 설정할 수 있도록 스키마를 고도화했습니다.
- **의도 파악 강화**: `CONVERSATION`이나 `INQUIRY` 중에도 모호한 점이 있으면 바로 `HUMAN` 상태로 진입하여 질문을 던집니다.

### 2. LangGraph Interrupt(중단점) 통합 (`graph.py`)
- **`interrupt_before=["PO"]` 설정**: 모든 작업 루프가 다시 수퍼바이저(PO)에게 돌아올 때 그래프를 일시 중단합니다. 이는 사용자가 현재까지의 작업 로그(`journals.md`)를 확인하고 다음 단계를 승인할 수 있는 "체크포인트" 역할을 합니다.
- **조건부 라우팅**: `HUMAN` 신호 발생 시 그래프를 즉시 종료(`END`)하여 REPL이 사용자 입력을 기다리도록 설계했습니다.

### 3. REPL 중단 및 재개 로직 구현 (`cli.py`)
- **Snapshot 감지**: 그래프 실행 중 `snapshot.next`를 체크하여 중단점 도달 여부를 실시간으로 감지합니다.
- **Approval Loop**: 중단점 도달 시 사용자에게 `Approval >` 프롬프트를 제공합니다.
  - `yes`/`y`: 기존 흐름대로 진행합니다.
  - `no`/`stop`: 현재 워크플로우를 중단합니다.
  - `명령어 입력`: 새로운 지시사항을 기존 상태와 병합하여 그래프를 재개합니다.

---

## 검증 시나리오

1. **승인 프로세스**: 사용자가 "파일을 하나 만들어줘"라고 입력하면, PO가 계획을 세운 후 실행 직전에 멈춥니다. 사용자가 `yes`를 입력해야 SA/CD로 전달됩니다.
2. **도움 요청**: 모호한 질문 입력 시, PO가 `▶ PO: 어떤 언어로 할까요?`와 같이 응답하며 `✋ Agent is waiting for your input...` 메시지와 함께 대기 상태로 진입합니다.
