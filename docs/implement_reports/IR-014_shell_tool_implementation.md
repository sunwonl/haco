# [IR-014] ShellTool 구현 및 에이전트 바인딩 (PO & CD)

**날짜**: 2026-04-12  
**단계**: Phase 5.5 — 도구 정합성 및 실행 능력 강화

---

## 구현 배경

기존 시스템은 에이전트들이 복잡한 터미널 명령(의존성 설치, 마이그레이션 등)을 실행할 수 있는 범용 도구가 부족했습니다. 특히 사용자의 단순 질의(예: "현재 파일 목록을 보여줘")에 대해 PO가 직접 답변하지 못하고 에이전트를 호출해야 하는 비효율을 발견했습니다.

---

## 구현 내용

### 1. `ShellTool` 클래스 개발 (`tools/shell.py`)
- **기능**: 동기식 Bash 명령어 실행 및 결과 반환.
- **보안 가드**: 
  - `FORBIDDEN_COMMANDS`: `rm -rf /`, `shutdown` 등 위험 명령 차단.
  - `Path Guard`: 프로젝트 루트 외부에서의 명령어 실행 제한.
  - `Non-interactive`: `PAGER=cat` 설정을 통해 대화형 프롬프트 강제 방지.

### 2. PO 에이전트의 상황 인지 능력(Environmental Awareness) 강화
- **도구 바인딩**: PO 노드에 `ShellTool`과 `FileIOTool`을 주입했습니다.
- **자동 컨텍스트**: 모든 PO 호출 시, 프로젝트의 파일 트리(`tree`)와 `git status` 결과를 프롬프트에 자동으로 포함합니다.
- **직접 응대**: PO가 인지된 환경 정보를 바탕으로 `INQUIRY` 요청에 대해 다른 에이전트 호출 없이 즉시 답변할 수 있게 되었습니다.

### 3. Core Developer 도구 통합
- **테스트 로직 개선**: `cd.py` 내부의 파편화된 `subprocess` 코드를 제거하고 `ShellTool`로 일원화했습니다.

---

## 검증 결과

- **PO 진단 테스트**: "프로젝트 구조를 알려줘" 요청 시, PO가 `ShellTool`로 얻은 트리 구조를 활용해 즉각 답변하는 것을 확인.
- **보안 테스트**: 금지된 명령어 패턴 포함 시 "Access denied" 혹은 "Forbidden" 에러 반환 확인.
