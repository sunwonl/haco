# [IR-007] QA Evaluator 에이전트 구현

**날짜**: 2026-04-11  
**단계**: Phase 2 — 에이전트 구현 (최종 검증 루프)

---

## 구현 내용

### 1. QA Evaluator 노드 (`agents/qa.py`)

#### 주요 기능
- **요구사항 대조 검증**: `user_prompt`와 실제 생성된 파일(`SystemState.file_changes`)의 내용을 대조하여 누락된 기능 확인.
- **테스트 결과 재검토**: CD가 보고한 테스트 성공 여부와 `latest_error`를 종합 분석.
- **승인/반려 의사결정**: 요구사항을 완벽히 충족하면 `APPROVED`, 미흡하면 `REJECTED`와 함께 구체적인 피드백 생성.
- **피드백 루프**: `REJECTED` 시 해당 내용을 `latest_error`에 담아 PO에게 전달하여 수정 유도.

#### QADecision (Structured Output)
- `status`: "APPROVED" | "REJECTED"
- `feedback`: 반려 시 상세 이유 작성

### 2. 파이프라인 통합 성공 (PO-SA-CD-QA)
- **최종 시나리오**: 계산기 스크립트 작성 및 테스트.
- **실행 결과**:
    - **SA**: 아키텍처 설계 완료.
    - **CD**: 설계 기반 코드 구현, `pytest` 통과, Git 커밋 완료.
    - **QA**: 전체 코드와 테스트 결과를 검토하여 최종 **APPROVED** 선언.
- **오케스트레이션**: PO가 각 에이전트의 결과를 보고 적절히 라우팅하여 `FINISH` 직전 단계까지 완벽하게 도달함 확인.

---

## 검증 내역
- ✅ QA 에이전트가 실제 파일 내용을 읽고 논리적으로 검증하는 프로세스 확인.
- ✅ `APPROVED` 신호가 발생했을 때 PO가 종료 단계로 진입하는 로직 확인.
- ✅ (Self-correction 확인) 이전 턴에서 발생한 임포트 에러를 PO가 인지하고 CD에게 재수정을 지시하는 지능형 루프 동작 확인.
