# [IR-018] 에이전트별 맞춤형 작업지시서(Custom Instructions) 구현

**날짜**: 2026-04-12  
**단계**: Phase 7 — 시스템 확장성 및 개인화

---

## 구현 배경

기존 시스템은 에이전트들의 시스템 프롬프트가 코드 내부에 하드코딩되어 있어, 특정 프로젝트나 유저의 스타일에 맞게 에이전트의 행동을 세밀하게 조정하기 어려웠습니다. 이를 해결하기 위해 각 에이전트에게 개별적인 "작업지시서(Markdown)"를 부여할 수 있는 기능을 추가했습니다.

---

## 구현 내용

### 1. 설계 방식: 파일 중심 접근 (Option 2)
- 모든 지시서는 `.harness/instructions/` 디렉토리 아래에 에이전트 식별자별 마크다운 파일로 관리됩니다.
- 예: `po.md`, `core_developer.md`, `qa_evaluator.md` 등.

### 2. `PromptManager` 유틸리티 개발 (`utils/prompt_manager.py`)
- **동적 로딩**: 에이전트 노드가 실행될 때, `PromptManager`가 해당 에이전트의 ID와 매칭되는 마크다운 파일을 찾아 내용을 읽어옵니다.
- **프롬프트 주입**: 읽어온 내용을 기본 시스템 프롬프트 하단에 자동으로 추가하여 LLM에게 전달합니다.

### 3. CLI 통합 및 부트스트랩
- **`harness init` 업데이트**: 새로운 프로젝트 시작 시 자동으로 `.harness/instructions/` 폴더를 생성하고, 각 에이전트별 기본 템플릿을 생성합니다.
- **템플릿 제공**: PO(한국어 설정), SA(설계 원칙), CD(품질 기준) 등 각 역할에 맞는 초기 가이드를 포함합니다.

---

## 사용 방법

유저는 언제든지 `.harness/instructions/` 폴더의 파일을 수정하여 에이전트에게 새로운 규칙을 부여할 수 있습니다.
- **예**: `core_developer.md`에 "모든 함수에 Docstring을 작성하고 80자를 넘기지 마"라고 추가하면, 이후 CD 에이전트는 이 규칙을 준수합니다.

---

## 검증 결과

- **동적 반영 테스트**: `po.md`에 "명사형 종결어미 사용" 지침 추가 후 PO의 답변 스타일이 즉시 변경됨을 확인.
- **하위 호환성**: 지시서 파일이 없는 경우에도 기존의 기본 프롬프트로 정상 동작함을 확인.
