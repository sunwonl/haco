# [IR-031] 에이전트 역할별 컬러 테마 적용 (CLI)

**날짜**: 2026-04-13  
**유형**: UX 개선 (Visual Design)

---

## 현상

기본 CLI 출력에서 모든 에이전트의 패널이 파란색 보더로 통일되어 있어, 현재 진행 중인 단계(기획, 설계, 구현, 검증)를 직관적으로 파악하기 어려웠음.

## 수정 내용

*   `src/harnesscore/cli.py`에 역할별 컬러 맵핑(Color Mapping) 적용:
    1.  **Planner (PO)**: `green` (초록색) - 관리 및 태스크 할당 단계 강조.
    2.  **Architect (SA)**: `magenta` (자주색) - 기술 설계 및 분석 단계 강조.
    3.  **Builder (CD, UI)**: `cyan` (청록색) - 실제 코드 구현 단계 강조.
    4.  **Reviewer (QA, DR)**: `yellow` (노란색) - 검증 및 품질 검사 단계 강조.
*   **UI 반영**: 각 에이전트의 응답 패널 보더와 핵심 텍스트에 해당 컬러를 적용하여 사용자에게 시각적 피드백을 강화함.

---

## 검증 결과
*   수정 후 워크플로우 진행 시, 단계가 바뀔 때마다 테마 컬러가 전환되어 현재 어떤 성격의 에이전트가 작업 중인지 한눈에 알 수 있게 됨.
