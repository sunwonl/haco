# [IR-026] API 키 로딩(load_dotenv) 로직 강화

**날짜**: 2026-04-13  
**유형**: 안정성 개선 (Reliability)

---

## 현상

외부 프로젝트 디렉토리에서 실행 시 `.env` 파일에 키가 설정되어 있음에도 불구하고 `API Key not set` 에러가 발생하는 현상 보고됨.

## 원인

*   기존 `load_dotenv()` 호출 시 인자를 전달하지 않아, 파이썬 프로세스의 현재 작업 디렉토리(CWD)에만 의존함.
*   환경 변수가 이미 프로세스 메모리에 (빈 값 등으로) 로드되어 있을 경우, 기본 `load_dotenv`는 이를 덮어쓰지 않아 의도한 키가 반영되지 않음.
*   `project_root` 설정에 따라 실제 프로젝트 위치가 현재 디렉토리와 다를 수 있는 시나리오를 고려하지 못함.

## 수정 내용

*   `HarnessConfig.resolve_api_key` 메서드 고도화:
    1.  `project_root`가 명시적일 경우 해당 경로의 `.env`를 우선적으로 탐색.
    2.  `load_dotenv(dotenv_path=..., override=True)`를 사용하여 시스템에 설정된 환경 변수보다 `.env` 파일의 값을 우선적으로 반영하도록 보장.
    3.  `strip()` 처리를 통해 키 전후의 불필요한 공백 제거.

---

## 검증 결과
*   수정 후 외부 디렉토리에서 `.env` 파일을 정상적으로 인식하여 `harness chat`이 성공적으로 실행됨을 확인.
