# [IR-030] CLI 시각적 UX 개선 (사고 과정/응답 분리)

**날짜**: 2026-04-13  
**유형**: UX 개선 (Visual Design)

---

## 현상

기존 CLI 환경에서는 에이전트의 답변이 단순 텍스트로 출력되어, 에이전트가 어떤 생각(Reasoning)을 거쳐 그런 결론을 내렸는지와 사용자에게 직접 하는 말을 구분하기 어려웠음.

## 수정 내용

*   `src/harnesscore/cli.py`에 `rich.Panel` 및 `rich.Text` 스타일링 적용:
    1.  **사고 과정 (Thinking)**: `dim italic` 스타일과 회색 보더(`bright_black`)를 가진 패널로 분리하여 에이전트의 내부 추론 과정을 시각적으로 구분.
    2.  **응답 과정 (Response)**: `bold cyan` 스타일과 파란색 보더(`blue`)를 가진 패널로 출력하여 사용자가 읽어야 할 핵심 메시지를 강조.
    3.  **아이콘 및 헤더**: 각 패널 상단에 🔍(Thinking), 💬(Response) 아이콘과 에이전트 이름을 표시하여 역할 식별성을 높임.
    4.  **여백 및 구조**: 패널 간 여백을 조정하고 핸드오프(Handoff) 메시지를 더 가독성 있게 개선.

---

## 검증 결과
*   수정 후 `harness chat` 실행 시, 에이전트의 작업 흐름이 훨씬 더 전문적인 대시보드 형태로 출력되며 정보의 계층 구조가 명확해짐을 확인.
